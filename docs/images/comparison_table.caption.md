# Critical exponents — cross-method comparison

Side-by-side bars of `Re(theta_i)` from every analogue path of the cross-analogue bridge: classical RG stability, transfer-matrix exponentiation, resolvent poles, and the hydraulic-impedance steady state. Bars within each group must match for the bridge to commute.
