# Spectral-sum convergence on `S^4`

![Spectral-sum convergence on `S^4`](./spectral_sum_convergence.png)

Trace of the Litim weight `W(z) = 1/(1 + z)` summed over the scalar Laplacian eigenvalues on `S^4` as a function of the angular-momentum cutoff `l_max`. Saturation diagnoses the smallest defensible truncation.
