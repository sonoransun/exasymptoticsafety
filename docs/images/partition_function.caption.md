# Heat-kernel partition function and free energy

![Heat-kernel partition function and free energy](./partition_function.png)

Two-panel plot of `Z(beta) = Tr exp(-beta H)` (log-log) and the free energy `F(beta) = -log Z / beta` for the scalar-field Laplacian on `S^4`. The high-temperature heat-kernel asymptote `(4 pi beta)^{-d/2} b_0` is overlaid.
