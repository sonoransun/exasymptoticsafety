# Asymptotic safety vs the string bootstrap (consistency)

![Asymptotic safety vs the string bootstrap (consistency)](./scattering_bridge.png)

Two-column physical-scattering consistency table. Both the asymptotically-safe and the Veneziano/Virasoro-Shapiro string amplitudes satisfy the foundational requirements (crossing, UV finiteness, bounded partial waves, no ghosts); they differ in the ultraviolet, where asymptotic safety softens to a UV-constant amplitude while strings are ultrasoft with an infinite higher-spin Regge tower. Distinct but mutually consistent points in amplitude space.
