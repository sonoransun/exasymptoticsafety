# Hydraulic network from the EH RG flow

![Hydraulic network from the EH RG flow](./hydraulic_network.png)

Auto-generated hydraulic network derived from the Einstein–Hilbert beta-function system at a reference NGFP guess. Nodes are coloured by pressure (the analogue of coupling value); pipe widths scale with diameter.
