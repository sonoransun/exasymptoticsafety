# VQRG cost landscape (2-parameter slice)

![VQRG cost landscape (2-parameter slice)](./vqrg_cost_landscape.png)

Filled `log10 C` contour of the variational-quantum RG cost function on a 2-parameter slice of the ansatz, with all other parameters held at zero. Deep wells correspond to RG fixed points (`C = 0`).
